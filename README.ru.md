# clawd in your ide!

[English](README.md) · **Русский**

Анимированный Клодик, который живёт над строкой ввода в десктопном приложении
Claude Code и отыгрывает то, чем Claude сейчас занят. Стоит без дела,
гуляет по островку, думает, рисует, бегает,
читает твои файлы, и машет флагом когда ход закончен.

<img src="docs/think.png" width="190" alt="Клодик думает">

## Как это выглядит

Он живёт на маленьком островке в углу над полем ввода — сам чат остаётся
нетронутым.

**Просто стоит.** Между ходами иногда радуется и время от времени
убегает в другую точку островка и обратно.

![стоит у края](docs/edge.png)
![бежит](docs/run.png)

**Работает.** Как только начался ход, анимация следует за ним: думает пока
думает модель, скользит на облачке, тягает гантели, рисует на холсте пока она
пишет.

![скользит на облачке](docs/glide.png)
![тягает гантели](docs/lift.png)
![рисует](docs/easel.png)

**Не мешает.** `/clawd off` убирает его совсем до конца сессии.

## Установка

Нужно **десктопное приложение** Claude Code — полоска рисуется на поверхности
`desktop` и прячется везде остальном (терминал, VS Code, мобильный).

```bash
git clone https://github.com/fitchiks/clawd-plugin.git ~/clawd-plugin
```

Дальше указать Claude Code на эту папку. Либо:

**Навсегда, в каждой сессии** — добавить в `~/.claude/settings.json`:

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "~/clawd-plugin"
  }
}
```

После этого перезапустить приложение целиком: переменная читается при старте
процесса, а не при открытии нового чата. Несколько путей разделяются `;` в
Windows и `:` в macOS/Linux.

**На одну сессию в терминале:**

```bash
claude --plugin-dir ~/clawd-plugin
```

## Команды

| Команда | Что делает |
|---|---|
| `/clawd` или `/clawd on` | Показать его |
| `/clawd off` | Спрятать до конца сессии |
| `/clawd <анимация>` | Проиграть одну анимацию после текущего шага |
| `/clawd debug` | Текущее состояние и последние отрисовки полоски |

Анимации: `idle`, `bounce`, `look`, `stretch`, `hop`, `think`, `glide`,
`paint`, `run`, `lift`, `detective`, `race`, `flag`, `dance`, `sparkle`.

На приветственном экране он не показывается — там хозяйничает штатный маскот —
и появляется, как только в чате есть первое сообщение.

## Как устроено

Один модуль хуков, `hooks/register.tsx`, около 440 строк:

- `session.start` регистрирует команду `/clawd`, восстанавливает, был ли он
  показан, и запускает таймер-пульс, который продвигает текущий сценарий.
- `prompt.submit`, `turn.step`, `tool.call` и `turn.complete` выбирают
  сценарий — список шагов `{ anim, ms, to }` — так что его занятие следует за
  занятием Claude.
- `ui.render` на `AbovePrompt` рисует его встроенным SVG: по спрайт-листу на
  анимацию, покадрово через `keyTimes`, плюс горизонтальный сдвиг, когда он
  перебегает с места на место.
- Позиция и текущая анимация лежат в `$.state` под ключом `clawd`, типы в
  `types/index.d.ts` — поэтому горячая перезагрузка модуля не сбивает его с
  места.

Тесты в `hooks/*.test.tsx` покрывают отрисовку полоски, финальный флаг и позу
при ошибке. Запуск:

```bash
claude plugin test .
```

Проверка типов — `tsc -p .`, после того как движок положит свои тайпинги рядом
с плагином.

## Картинки

Самого Клода нарисовал **@volodya**, стикерпак [AIByVolodya](https://t.me/addstickers/AIByVolodya).
Спрайт-листы в `hooks/sprites.ts` - это его стикеры, перерисованные покадрово в
PNG-листы. Используются с его разрешения, спасибо ему.

Рисунки остаются его. Лицензия MIT ниже покрывает код в этом репозитории, но не
графику: если будете форкать и хотите оставить Клодика - пожалуйста, спросите и у него. Чтобы
поставить своего персонажа, замените `hooks/sprites.ts` - подойдёт что угодно той
же формы `{ png, frames, dur, keyTimes, xs, top, bottom, body, cx }`, больше в
модуле менять ничего не нужно.
